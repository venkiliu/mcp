name: ov-work-memory-settings
description: 用户明确要求开启、关闭或查看当前 Codex 配置的公司 OpenViking 工作记忆时使用。管理工作记忆开关。
---

使用本插件随附的 `../../scripts/work-memory-settings.mjs`，从本 SKILL.md 的目录解析实际路径。在当前 Codex 的用户和工作目录运行 Node.js；员工个人知识库凭据由插件读取。

- **启用**。告诉员工，启用后，当前 Codex 可以把未来对话中明确、可复用的工作偏好、已定事项和工作规范，记入本人名下的公司 OpenViking 知识库，授权管理员可查看。用户已了解并要求开启时，直接执行 `node "<脚本绝对路径>" --enable`。用户只是询问功能、查看状态、安装或更新插件时，保持当前选择。只有用量统计同意不等于工作记忆同意。
- **查询**。执行 `--status`，按实际输出报告。`connection-changed` 表示当前个人知识库连接不匹配，需要本人核对账号后重新启用。启用只代表以后可以记录；生成与否取决于对话中有没有值得留下的工作事项，并以知识库中可读的实际条目为准。
- **停用**。执行 `--disable` 停止自动写入新条目。已有工作记忆可以另按用户指定的具体条目查阅或处理。
