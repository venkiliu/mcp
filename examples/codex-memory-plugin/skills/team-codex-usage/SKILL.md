name: team-codex-usage
description: 仅在用户要求启用、查看状态或停止这台电脑上团队 Codex Token 用量统计时使用。
---

使用此团队插件自身的 `../../scripts/company-usage/trigger.mjs`（路径相对于本 SKILL.md 所在目录），以当前平台的 Node 18+、当前系统用户和当前 Codex 配置运行。不要从网上下载脚本。个人 OpenViking 配置由插件读取，无需向用户索要或输出密钥。

首次启用前让员工了解，个人知识库身份会关联本 Codex 配置里现存及以后的会话统计，包括活跃与归档会话中的日期、模型、会话去重标识，以及输入、缓存、输出 Token 数，团队管理员可以在知识库查看。用量报告仅含这些统计字段。已有 OpenViking 记忆对话同步按原有设置工作。若用户的请求已明确表示知道上述范围并同意启用，直接执行，无需重复确认。仅安装、查看帮助或查询状态均不代表同意。

- 已获得本人确认后，以 `node <实际脚本绝对路径> --enroll` 登记。报告是否登记成功。提醒在 Codex 提示时允许团队插件 hooks，重新打开 Codex 并完成一次日常会话。
- 查询状态用 `--probe`。尚无 lastRun 表示还没有真实 hook 成功上报。
- 用户要求停用时执行 `--unenroll`。已运行的独立旧版采集器如仍在工作，应另外告知用户，并就完整停用按公司提供的旧版流程处理。
- 身份或服务器变更时先核对当前员工账号和目标知识库。不得自动重新绑定其他账号。
